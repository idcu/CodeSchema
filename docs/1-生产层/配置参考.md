## 0. 优先级与变量命名

优先级：**默认值 < 配置文件 < 环境变量 < CLI 参数**。所有项均有默认值，不配置也可运行。

环境变量格式：`CODESCHEMA_<SECTION>_<KEY>`（下划线转大写），如：
- `CODESCHEMA_SERVER_MCP_ADDR=:9090`
- `CODESCHEMA_SERVER_AUTH_TOKEN=xxx`
- `CODESCHEMA_SCANNER_WORKERS=8`
- `CODESCHEMA_STORAGE_DSN=E:\data`

## 1. 配置节总览

| 节 | 用途 | 关键键 |
|---|---|---|
| `preset` | 能力层预设（一键组合能力） | `minimal` / `semantic` / `multitenant` / `""`（默认） |
| `project` | 项目元信息、默认仓库 | `name`、`root`、`languages` |
| `storage` | 存储驱动/DSN/KV/向量/搜索 | `driver`、`dsn`、`kv`、`vector.*`、`search.*` |
| `parser` | 解析适配器与其他源 | `adapters`、`scip.*`、`codegraph.*`、`jcodeindexer.*`、`lsp.enabled` |
| `ai` | AI 增强（预算硬限） | `provider`、`base_url`、`api_key`、`model`、`budget_*` |
| `server` | MCP/HTTP 监听与认证 | `mcp_addr`、`http_addr`、`auth_token` |
| `watcher` | 增量监听 | `enabled`、`debounce_ms`、`ignore_dirs`、`use_fsnotify` |
| `scanner` | 扫描并发与文件上限 | `workers`、`file_size_limit_mb`、`line_count_limit` |
| `tenants` | 多租户（可选） | `[]{id,name,root,storage.dsn,auto_scan,watch}` |

## 2. 逐键说明（默认值以 `config.yaml.example` 为准，此处摘录）

### preset（能力层预设，可选）
- `""`（默认）：不调整能力组合，完全使用显式配置（向后兼容）。
- `minimal`：最小资源档——仅 FTS 检索，关语义/向量/ONNX，关 AI 增强（`budget_*` 归零），适合低内存/快速索引。
- `semantic`：语义档——FTS + 语义检索（向量/ONNX），保持 AI 增强。
- `multitenant`：多租户档——保持全能力，增量监听默认开启，租户在 `tenants` 声明。
- 预设是能力组合的权威来源：配置了 preset 后，其管理字段以 preset 为准；未管理字段保持显式配置。未知值在加载时归一为空。

### project
- `name`（`"my-project"`）标识与日志；`root`（`"/path/to/your/repo"`）scan/watch 默认路径；`languages`（`go,java,python,typescript,rust,cpp`）影响解析器选择。

### storage
- `driver`：`file`（默认，JSON 零依赖）｜`sqlite`（modernc 纯 Go）｜`pg`（需 `-tags pg`）｜`kv`（需 `-tags redis`）。
- `dsn`（`"./data"`）索引持久化目录。
- `kv`：Redis 地址，空则关闭 L2 缓存（需 `-tags redis`）。
- `vector.*`：`driver`（占位 chromem，当前生产固定 PersistentStore+MemoryStore）、`dsn`、`embedding_model`（`bge-small-zh-v1.5`）、`model_dir`（`./down/models/<model>`）、`model_download_url`（远程分发，支持 `{model}` 占位）、`model_sha256`（下载校验，不匹配拒绝解包）。
- `search.*`：`fts`（`true`）、`semantic`（`true`）、`fts_dir`、`vector_dir`、`vector_dim`（`1024`，128-1024）、`idf_dir`。

### parser
- `adapters`（`[treesitter]`）启用的解析适配器。
- `scip.index_dir`（`"./scipout"`）；`codegraph.db`；`jcodeindexer.{db,config_file,env}`（仅配置预留）。
- `lsp.enabled`（`false`）：启用后按语言分发 gopls/jdtls/clangd，失败自动回退 tree-sitter。

### ai
- `provider`（`openai`）、`base_url`（空则禁用 AI）、`api_key`（空则禁用）、`model`（`gpt-4o-mini`）。
- `budget_per_scan`（`100`）、`budget_per_query`（`10`）——每次扫描/查询 AI 调用硬限，超限返回 `ErrBudgetExceeded`。
- 注：缺 `base_url`/`api_key`/`model` 任一即禁用 AI 增强（规则标签与索引不受影响）。

### server
- `mcp_addr`（`:8080`）MCP 监听；`http_addr`（`:8081`）HTTP/REST 监听。
- `auth_token`（空 = 不认证）：生产**必须设置**，MCP/HTTP Bearer 认证。
- `rate_limit`（`0` = 不限流）：全局限流，每分钟请求上限（令牌桶，突发=上限）。
- **热重载**：以上 3 项（含 `http_addr` 监听地址）在 `--config` 模式下变更**无需重启进程**即生效（见下文 tenants 热重载说明）。

### watcher
- `enabled`（`true`）、`debounce_ms`（`300`）、`ignore_dirs`（`.git/node_modules/target/build/vendor/dist/.next`）、`batch_size`（`50`）、`use_fsnotify`（`false`，默认轮询）。

### scanner
- `workers`（`4`）、`file_size_limit_mb`（`10`）、`line_count_limit`（`50000`）。大仓库调参见 [性能调优](../2-交付层/性能调优.md)。
- **热重载**：以上 3 项（`workers` / `file_size_limit_mb` / `line_count_limit`）在 `--config` 模式下变更触发对应租户实例重建（`tenant.Manager.Apply`），无需重启进程。

### tenants（多租户）
- `[]`：每项 `id/name/root/storage.dsn/auto_scan/watch`；索引按各自 `storage.dsn` 派生**隔离**。不配置则退化为单 `default` 租户（与原单项目模式完全一致）。示例见 `build/mt-demo.yaml`。
- **热重载**：serve / mcp 在 `--config` 模式下自动监听配置文件，`tenants` 列表变更（新增/移除/关键字段修改）自动增量更新租户集合，无需重启进程；仅关键字段（DSN/Root/Name/auto_scan/watch/scanner 三项）变化触发重建。

## 3. 环境变量速查（部分）

|---|---|
| `CODESCHEMA_SERVER_MCP_ADDR` | `server.mcp_addr` |

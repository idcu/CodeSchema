# P8_6 健壮性组件 【公共模块】

> 模块编号：P8_6 ｜ 父模块：P8 横切公共模块 ｜ 完成度：100% ｜ 代码：`internal/robust`（graceful.go 233 行 / retry.go 218 行 / recovery.go）

## 🎯 模块用途

提供三类生产级健壮性能力：

1. **优雅关闭**（`GracefulManager`，30s 全局超时，二次信号强制退出）
2. **重试机制**（指数退避 + 上限）
3. **Panic 恢复**（`runtime/debug` 捕获 + 日志）

解决「进程退出丢数据、外部调用抖动即失败、goroutine panic 打挂服务」三类问题。

## 🧱 拆分逻辑说明

按**职责边界（横切能力）**独立：三类能力被长驻进程（server/watcher/scheduler）与外部调用方（lsp 适配器）共享。独立成模块后，重试策略/关闭流程可全局统一调整。

## ⚙️ 技术说明

**技术选型**：Go 标准库 `context`/`os/signal`/`runtime/debug`/`math/rand`/`time`；依赖 `internal/log`。

**对外接口契约**：
- `NewGracefulManager(timeout)` + `RegisterFunc(name, fn)` + `Shutdown(ctx)`
- `ForceExitOnSecondSignal(graceful)` — 二次信号兜底
- `Retry` 系列（指数退避）
- `Recover`/`SafeGo`（panic 恢复）

**依赖的下层模块**：P8_2 日志。

**数据模型**：无。

## 🔄 替代方案

- 用标准库裸写每处：优雅关闭流程/重试参数分散，必然不一致；统一组件是正解。
- 引入 resilience 库（go-resilience）：能力重叠但引入依赖，当前三件套足够。

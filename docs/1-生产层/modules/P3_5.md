# P3_5 CodeGraph 适配器

> 模块编号：P3_5 ｜ 父模块：P3 解析层 ｜ 完成度：92% ｜ 代码：`internal/parser/adapter/codegraph`

## 🎯 模块用途

对接 **CodeGraph 图数据库**（SQLite 承载的代码图谱数据源）提取符号关系。面向「已有第三方 code graph 产出、希望直接复用图谱」的场景，避免重复解析。

## 🧱 拆分逻辑说明

按**数据来源（DB 图数据）**独立：CodeGraph 是外部图谱产物，与 Treesitter（自带解析）、SCIP（索引文件）、LSP（语言服务）来源形态都不同；独立成模块使其成为「可选数据源积木」，不影响主解析链路。

## ⚙️ 技术说明

**技术选型**：`modernc.org/sqlite`（纯 Go 免 CGO）直连 codegraph DB；`database/sql` 查询接口。

**对外接口契约**：实现 `parser.ParserPlugin`；从 SQLite 图库查询节点/边并归一化为 `IRDocument`。

**依赖的下层模块**：P3_1 解析核心、P8_5 错误体系、`modernc.org/sqlite`。

**数据模型**：图节点/边表 → `parser.IRDocument`（class/method/call）。

## 🔄 替代方案

- 让用户直接用 codegraph 工具而非本系统：图谱无统一 IR，无法供检索/分析使用，接入适配是正解。
- 放弃该数据源：主链路（Treesitter/LSP）已覆盖常见场景，codegraph 是增益项。

## 📊 完成度：92%

已做：SQLite 图库读取、IR 归一化、基础注册接入、**真实 CodeGraph schema（nodes/edges）双契约自适应端到端测试**（`TestCodeGraphAdapter_ParseAll_RealSchema`，含类/方法/调用关系按文件归属提取）、schema 形态检测优先级（真实优先）、缺失表/非法库显式报错降级、**Schema 变体兼容覆盖**（role/confidence 额外列不干扰读取、interface/enum/trait/module/record/constructor kind 变体类型映射、缺列 schema 漂移显式报错不静默）。

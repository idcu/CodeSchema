# P1_3 HTTP API 与可视化

> 模块编号：P1_3 ｜ 父模块：P1 接入层 ｜ 完成度：100% ｜ 代码：`internal/server/http.go` + `viz.go` + `openapi_handler.go`

## 🎯 模块用途

提供 RESTful HTTP API 供脚本/浏览器调用，并承载**向量索引可视化仪表盘**（`/viz`）：支持文档浏览、文本检索、向量索引状态查看，让语义检索的能力可被肉眼观测与调试验证。

## 🧱 拆分逻辑说明

按**技术分层（协议入口）**独立：HTTP 采用请求/响应模型、Bearer token 认证、与浏览器直连，与 MCP 的双向 JSON-RPC 形态截然不同。`/viz` 可视化是 P17 阶段新增的能力，与核心 API 共用同一 Service 与向量索引（避免 embedding 不一致），故合并为同一模块。

与兄弟模块的边界：HTTP 只做「REST 转译 + 认证 + 静态页面托管」，业务全部委托 P2_1 Service。

## ⚙️ 技术说明

**技术选型**：Go 标准库 `net/http`（无 Web 框架）；`html/template` 渲染 `/viz` 页面；Bearer token 中间件。

**对外接口契约（HTTP 端点）**：

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/symbols?q=` | GET | 符号搜索（双路检索） |
| `/api/context?symbol=` | GET | 符号上下文 |
| `/api/impact?method=&depth=` | GET | 影响面分析 |
| `/api/tests?method=` | GET | 关联测试 |
| `/api/tags` 等 | GET | 标签体系查询 |
| `/api/health` | GET | 健康检查 |
| `/viz` | GET | 向量索引可视化仪表盘 |
| `/openapi` | GET | API 文档 |

**依赖的下层模块**：P2_1 Service、P5_1 检索、P6_1 向量索引（/viz 复用同一 VectorStore）、P8 公共模块。

**数据模型**：JSON 响应结构（搜索/上下文/影响面结果），由 Service 定义。

## 🔄 替代方案

- `gin`/`chi` 框架：路由/中间件更丰富，但当前端点数量少，标准库可控且零依赖。
- `/viz` 独立前端工程（React/Vue）：交互更强，但需引入 Node 构建链，与「单二进制部署」目标冲突，当前 `html/template` 足够。

## 📊 完成度：100%

> 向量索引可视化：`/viz`（及 `/viz/api/document` `/viz/api/documents` `/viz/api/overview` `/viz/api/search`）由 `internal/server/viz.go` 单独注册，已计入上方 23 路由（`http.go` 17 + `viz.go` 6）。计数脚本 `scripts/project_counts.py` 扫描 `internal/server/*.go`（排除 `mcp*.go` 与 `*_test.go`），`mcp.go` 的 `/sse` `/message` 属 MCP 传输端点、不计入 HTTP API 路由。

> 查询参数契约（2026-11-14 与 OpenAPI 对齐）：`/context` 用 `symbol` / `symbols`（批量）；`/impact`、`/tests` 用 `method` / `methods`（批量）；`/affected` 主参数为 `method`，`symbol` 为兼容别名，另支持 `recursive`；`/search` 支持 `min_score`；`/context` 支持 `chars_per_token`。`GET /openapi.json` 为单一事实源。
> 测试关联候选（`FindTestLinks`，`/tests` 与 `/affected` 共用）：按类名 `*Test`/`Test*`/`*Tests`/`*Spec` 发现测试类；Go 额外把 `*_test.go` 的合成 `PACKAGE` 容器按「同目录同包」归属到该目录全部生产类，覆盖包级 `TestXxx`/`BenchmarkXxx`/`ExampleXxx`（包级 helper 不参与命名匹配）。方法名匹配按词边界：`Analyze` 不命中 `Analyzer`；JUnit 描述型方法名允许目标方法名为前缀（`processCreationFormSuccess` ↔ `processCreationForm`），目标名 <4 字符时禁用前缀匹配（P2-4 语义保留）。策略链：`explicit(100)` → `call_graph(95)` → `dependency(80)` → `naming(70)` → `same_tag(60)`；`call_graph` 按测试文件的直接调用边反查目标方法，覆盖行为型测试名与跨类测试，并对 `entity.setName` / 带包名 caller 做 FQN 归一。`coverage(90)` 策略已于 2026-11-14 删除（生产从未接线，`SetCoverage`/`LoadGoCoverProfile` 零调用点）。
> 认证：请求头 `Authorization: Bearer <auth_token>`（`server.auth_token` 非空时）。
> 错误脱敏（R2-8）：受控错误按 `ERR_*` 码返回；**非受控内部错误**（可能含 SQL/DSN/绝对路径）只写服务端日志，HTTP 统一返回 `ERR_INTERNAL` + `internal server error`，MCP 返回 `-32603 internal error`；未知租户固定 `404 ERR_UNKNOWN_TENANT`（不回显租户 ID 之外的内部细节）。
> 客户端可访问 `GET /openapi.json` 与 `/docs` 自助查阅。

## MCP 工具（12 个，`internal/server/mcp.go`）

`context` · `impact` · `tests` · `affected` · `get_call_graph` · `search_config` · `find_dependencies` · `search_symbols` · `get_tags` · `search_by_tag` · `get_all_tags` · `list_projects`

> 语义聚焦：`find_dependencies` 返回指定符号在调用图上的下游依赖（callees）FQN 列表；`search_config` 对类/方法的 `FullName`/`Name`/`Doc`/`Signature`/`ReturnType` 做大小写不敏感子串匹配（注解文本经 `Doc` 覆盖），返回命中符号 FQN。

传输：JSON-RPC 2.0 over SSE（`--addr`）+ stdio（`--stdio`）。`--print-config` 输出 5 类客户端接入片段。

- **SSE（MCP 2024-11-05）**：`GET /sse` 先下发 `event: endpoint`，`data` 为 `/message?sessionId=<id>`；客户端向该地址 `POST` JSON-RPC，服务端返回 **202** 且不内联回包，响应经同一 SSE 流的 `event: message` 推送。无 `sessionId` 的 POST 返回 400。
- **stdio**：每行一条 JSON-RPC 消息（UTF-8，非 LSP `Content-Length` 帧）；通知（无 `id`）不回包；解析失败回 `id: null` 的 `-32700`；单行上限 16MB；stdin EOF 优雅退出。
- 工具调用继承请求上下文，客户端断开/取消会传递给底层服务（不再使用 `context.Background()`）。

### `context` 工具裁剪参数（输出预算与批量）

`context` 面向 Agent 的「精准裁剪」入参，同时支持单符号与批量：

| 参数                         | 说明                                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `symbol` / `symbols`       | 单符号用 `symbol`；一次取回 N 个符号用 `symbols`（数组，等价旧写法跨 N 轮，B5）。批量时单符号失败不中断整体：`results` 只含成功项，失败详情落在 `errors[]`（带 `code` + `hint`） |
| `context_lines`            | 语义块外扩的上下文行数（默认 5）                                                                                                        |
| `mode`                     | `full`（默认源码原文）/ `minimal`（仅元数据，评测基线）                                                                                     |
| `max_bytes` / `max_tokens` | 输出预算（`<=0` 不限），两者取更严者。超限按「缩上下文 → 块内截断 → 仅首行」自动降级，`_trace.degraded=true` 并回传 `degrade_reason`（B1）                         |
| `max_line_chars`           | 单行字符上限，防超长行吃掉整份预算                                                                                                        |
| `path_style`               | `absolute`（默认）/ `virtual`（映射为 `/codebase` 虚拟根，B9）                                                                        |

HTTP 端点 `GET /context` 等价支持：批量用 `?symbols=a,b,c`；预算/裁剪参数同名（`max_bytes` / `max_tokens` / `max_line_chars` / `path_style`）。完整契约以 `GET /openapi.json` 为准。

## 扩展接口

- 新增 MCP 工具：在 `mcp.go` 的 `[]mcpTool` 中追加 `Name/Description/Handler`，并同步文档与 `counts` 基线。

- 新增 HTTP 路由：在 `http.go` 的 `mux.HandleFunc` 注册，注意 `middleware` 链（CORS/recovery/auth/rate-limit）。

- 接口变更属破坏性，先标注影响范围再评审（见 [04-贡献者](../04-贡献者/README.md)）。

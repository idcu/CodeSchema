# 接口层（CLI / HTTP / MCP）

> 写给：要调用或扩展接口的开发者

> 最后更新：2026-09-02
## CLI 子命令（`cmd/codeschema`）

| 命令 | 作用 |
|---|---|
| `scan <path>` | 扫描仓库并入库 |
| `watch <path>` | 文件监听增量（`--fsnotify` 切原生监听，默认轮询，300ms 防抖） |
| `rebuild-kv` | 重建 KV 缓存（P2） |
| `serve` | 启动 HTTP API Server（`--http :8081`） |
| `mcp` | 启动 MCP Server（`--addr :8080`，`--stdio` 走 stdio 直连） |
| `benchmark <path>` | 扫描/索引/检索全链路基准 |
| `agent-bench` | Agent 任务端到端评测（多仓库 `--repos` + RepoHint 过滤） |
| `version` | 查看版本 |

## HTTP API（`internal/server/http.go` 注册 16 路由）

| 路由 | 说明 |
|---|---|
| `/health` `/health/db` `/health/kv` `/health/vector` | 健康检查（含各后端） |
| `/context` | 取符号精准裁剪上下文 |
| `/impact` | 方法调用影响面 |
| `/tests` | 关联单测查询 |
| `/search` | 符号检索（精确/语义/融合，`min_score` 置信度过滤） |
| `/tags` `/tags/search` `/tags/all` | 标签查询 |
| `/projects` | 枚举多租户仓库 |
| `/metrics` | Prometheus 指标 |
| `/openapi.json` | OpenAPI 文档 |
| `/docs` `/docs/` | API 文档页 |

> 向量索引可视化：`/viz`（及 `/viz/api/document` `/viz/api/documents` `/viz/api/overview` `/viz/api/search`）由 `internal/server/viz.go` 单独注册，**不计入上述 16 路由**——计数基线 `scripts/counts_baseline.json` 的 `http_routes=16` 仅统计 `http.go`。

> 认证：请求头 `Authorization: Bearer <auth_token>`（`server.auth_token` 非空时）。
> 客户端可访问 `GET /openapi.json` 与 `/docs` 自助查阅。

## MCP 工具（12 个，`internal/server/mcp.go`）

`context` · `impact` · `tests` · `affected` · `get_call_graph` · `search_config` · `find_dependencies` · `search_symbols` · `get_tags` · `search_by_tag` · `get_all_tags` · `list_projects`

传输：JSON-RPC 2.0 over SSE（`--addr`）+ stdio（`--stdio`）。`--print-config` 输出 5 类客户端接入片段。

## 扩展接口

- 新增 MCP 工具：在 `mcp.go` 的 `[]mcpTool` 中追加 `Name/Description/Handler`，并同步文档与 `counts` 基线。
- 新增 HTTP 路由：在 `http.go` 的 `mux.HandleFunc` 注册，注意 `middleware` 链（CORS/recovery/auth/rate-limit）。
- 接口变更属破坏性，先标注影响范围再评审（见 [04-贡献者](../04-贡献者/README.md)）。

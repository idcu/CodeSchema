## 发布流

1. 打 tag：`git tag vX.Y.Z && git push origin vX.Y.Z`（触发 `release.yml` 构建 5 平台制品）。
2. **本页追加**一个新版本段落：新增（功能）、修复（bug）、已知问题。
3. 若涉及行为/配置变更，同步 [用户操作手册](../3-使用层/用户操作手册.md)、[配置参考](../1-生产层/配置参考.md)。

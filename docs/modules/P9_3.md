# P9_3 AdapterBench 适配器验证

> 模块编号：P9_3 ｜ 父模块：P9 测试与基准 ｜ 完成度：95% ｜ 代码：`internal/adapterbench`（bench_ast_gate.go / bench_ast_gate_treesitter.go）

## 🎯 模块用途

提供解析适配器的**精度对比基准**：同一批真实 fixture 分别在「AST gate（期望结果）」「正则启发式」「treesitter 语法树」等解析路径下运行，对比提取精度（类/方法/调用关系命中率）。输出 `build/adapter-bench.json` 与 `analysis/2026-08-14-adapter-validation.md` 分析报告。

## 🧱 拆分逻辑说明

按**职责边界（精度验证专项）**独立：精度是解析层（P3）的核心质量指标，需要一个独立、轻量、可秒级运行的验证包——**刻意不依赖 onnxruntime 等 cgo 重型依赖**，仅依赖 lsp/scip/treesitter 适配器，工具缺失时优雅跳过。

## ⚙️ 技术说明

**技术选型**：Go `testing` + 独立验证 runner；真实 fixture 集。

**对外接口契约**：`adapter_validation_test.go` 端到端验证 + AST gate 对比基准；输出 JSON 报告。

**依赖的下层模块**：P3_2 Treesitter、P3_3 SCIP、P3_4 LSP。

**数据模型**：验证结果 JSON（解析路径 × fixture × 精度指标）。

## 🔄 替代方案

- 手工对比适配器输出：不可重复、不可回归；自动化基准是 P14/P17 验证工作的沉淀。

## 📊 完成度：95%

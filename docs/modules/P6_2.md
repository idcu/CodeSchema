# P6_2 嵌入器（Local / ONNX）

> 模块编号：P6_2 ｜ 父模块：P6 向量索引层 ｜ 完成度：95% ｜ 代码：`internal/vector`（embedder.go / embedder_local.go / embedder_onnx.go / embedder_onnx_stub.go）

## 🎯 模块用途

把文本/符号语义转换为向量。两个实现：

- **LocalEmbedder**：自研 TF-IDF + 降维（dim 512），零依赖、离线可用、免 CGO，默认路径。
- **ONNXEmbedder**：bge-small-zh-v1.5 模型 ONNX 推理，语义质量高，需 gcc + onnxruntime 动态库（`-tags onnx`）。

工厂 `NewONNXEmbedderOrFallback` 保证模型不可用时自动降级到 Local——语义检索永远可用。

## 🧱 拆分逻辑说明

按**算法路径**独立：两实现满足同一 `Embedder` 接口，算法升级（换模型、调维度）只影响本模块。ONNX 路径用 `//go:build onnx` 隔离，保证默认构建免 CGO/gcc。

## ⚙️ 技术说明

**技术选型**：自研 TF-IDF 嵌入；`onnxruntime_go`（本地 patch 适配 API v23，`third_party/onnxruntime_go_patch`）；IDF 词典复用 P5 的 idf.json。

**对外接口契约**：
- `Embedder` 接口：`Embed(ctx, text) ([]float32, error)` / `Dim() int`
- `NewLocalEmbedder(dim)` — TF-IDF 嵌入器
- `NewONNXEmbedder(modelDir, dim, libDir)` / `NewONNXEmbedderOrFallback(...)` — ONNX 或自动降级
- `NewMockEmbedder(dim)` — 测试用

**依赖的下层模块**：P8_2 日志、P6_3 模型分发（模型文件就位）。

**数据模型**：TF-IDF 词权重向量；ONNX 模型输出 dim=512 向量。

## 🔄 替代方案

- 只用 ONNX：默认构建依赖 gcc + 动态库，违背免 CGO 目标，不可取。
- 只用 Local：语义质量低（无大模型语义）；双路径 + 自动降级是最优取舍。

## 📊 完成度：95%

已做：Local 嵌入器（TF-IDF + IDF 加载）、ONNX 嵌入器（dim=512 真实推理验证）、自动降级工厂、`-tags onnx` 构建隔离、**语义质量定案**（`embedding_quality_test`：ONNX Recall@1=1.00 vs Local 0.42，ONNX 全面碾压，非默认路径仅作质量兜底）。
未做：ONNX 模型在真实环境的多仓库 recall 持续对比基准（质量看护可并入 CI）。

## 🚧 阻塞与风险

- ONNX 路径需外部动态库与模型文件（~47MB），环境依赖重（见总览阻塞项 2）。
- Local 嵌入器语义质量上限低（R@1=0.42）——**语义检索默认路径质量受限是当前已知取舍**，生产高精度语义检索需 `-tags onnx`。

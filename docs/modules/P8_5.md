# P8_5 错误体系 【公共模块】

> 模块编号：P8_5 ｜ 父模块：P8 横切公共模块 ｜ 完成度：100% ｜ 代码：`internal/errors`（errors.go）

## 🎯 模块用途

定义统一错误类型与分类，供各包错误传递与上层分类处理（错误 wrapping、可判定错误类别）。解决「错误无类型、上层只能字符串匹配」的问题。

## 🧱 拆分逻辑说明

按**职责边界（横切能力）**独立：错误类型被适配器（lsp/scip/codegraph）与 AI 层依赖，上层（cmd）按类型决定是警告还是致命。独立成模块保证错误契约全局唯一。

## ⚙️ 技术说明

**技术选型**：Go 标准库 `errors`（`%w` wrapping + `errors.Is/As`）。

**对外接口契约**：预定义错误类型/类别 + 构造函数 + 分类判断函数。

**依赖的下层模块**：无。

**数据模型**：错误类型枚举（按模块分类）。

## 🔄 替代方案

- 每包自造错误：跨包类型判断失效（如 cmd 需要区分「配置缺失」与「解析失败」），不可取。

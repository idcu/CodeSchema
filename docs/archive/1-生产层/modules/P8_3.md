# P8_3 指标采集 【公共模块】

> 模块编号：P8_3 ｜ 父模块：P8 横切公共模块 ｜ 完成度：100% ｜ 代码：`internal/metrics`（metrics.go 311 行）

## 🎯 模块用途

提供基础指标采集（Prometheus 文本格式），供监控系统抓取。覆盖扫描/解析/服务的关键计数与耗时。解决「系统黑盒、无法观测健康与性能」的问题。

## 🧱 拆分逻辑说明

按**职责边界（横切能力）**独立：指标命名、格式、暴露端点全局统一，业务包只调 `metrics.Xxx.Inc()` 这类简单接口。独立后新增指标维度不影响业务逻辑。

## ⚙️ 技术说明

**技术选型**：手写 Prometheus 文本格式（计数器/直方图），无 client-go 依赖。

**对外接口契约**：计数器/直方图对象 + 注册/快照/文本渲染接口；`/metrics` 端点由 server 暴露。

**依赖的下层模块**：无。

**数据模型**：指标注册表（名称 → 类型/维度）。

## 🔄 替代方案

- Prometheus client-go：类型与历史 API 更全，但对单服务指标量级偏重；手写文本格式足够且零依赖。
- 不用指标：无法监控扫描吞吐与检索耗时，可观测性目标是 P6 明确诉求。

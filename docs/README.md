## 一、定位速览

**CodeSchema** —— 面向 AI 辅助开发的代码元数据索引与上下文裁剪服务（Go 1.25.2，生产级）。
扫描仓库 → 提取类/方法/接口/调用关系等结构化数据 → 三层存储（file/SQLite/PG + Redis + 向量/全文检索）→ 经 MCP/HTTP 向 AI Agent 供给精准裁剪后的代码上下文。

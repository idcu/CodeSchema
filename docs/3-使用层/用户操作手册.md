> 写给谁：使用 CodeSchema 的开发人员、运营、AI 工具维护者
> 写什么：构建/启动、全量扫描、增量监听、MCP/HTTP 服务、可视化、常用命令与配置

## 0. 快速开始（30 秒）

```bash
make build                                   # 构建（纯 Go，免 CGO）
./codeschema scan ./your-repo                # 扫描仓库建立索引
./codeschema mcp --store ./data              # 启动 MCP Server（AI 工具接入）
# AI 工具连接：http://localhost:8080/sse
```

## 1. 命令总览

| 命令 | 用途 |
|---|---|
| `scan [--workers N] <path>` | 全量扫描仓库，建立索引 |
| `watch [--fsnotify] [--debounce N] <path>` | 增量监听文件变更并更新索引 |
| `mcp [--addr :8080] [--stdio] [--store DIR] [--print-config]` | 启动 MCP Server（SSE/stdio） |
| `serve --http :8081` | 启动 HTTP API（含 `/viz` 可视化、`/openapi`） |
| `benchmark <path> [--out FILE]` | 运行全链路基准并输出 JSON |
| `rebuild-kv` | 从基础存储全量重建 Redis KV 缓存 |
| `version` | 打印版本与构建信息 |

## 2. 构建与启动

```bash
make build              # 等价 go build -o build/codeschema ./cmd/codeschema
./codeschema version
```
配置：复制 `config.yaml.example` → `config.yaml`，改 `project.root` 等后 `./codeschema --config config.yaml serve`。优先级：默认 < 配置文件 < 环境变量到 CLI 参数。

## 3. 全量扫描

```bash
./codeschema scan ./your-repo
./codeschema scan --workers 16 ./large-repo      # 调并发
```
大仓库建议调参，见 [性能调优](../2-交付层/性能调优.md)。扫描完成后数据落在 `storage.dsn`（默认 `./data`）。如启用语义检索需 `-tags onnx` 构建并确保模型已下载（`make models-serve` 分发）。

## 4. 增量监听

```bash
./codeschema watch ./your-repo                   # 轮询
./codeschema watch --fsnotify --debounce 200 ./repo  # 原生监听+短防抖（高频修改场景）
```
监听忽略目录与批量大小在 `watcher.ignore_dirs` / `batch_size` 配置。

## 5. MCP Server（供 AI 工具）

```bash
./codeschema mcp --addr :8080                # SSE；AI 连 http://localhost:8080/sse
./codeschema mcp --stdio --store ./data      # 原生 stdio
./codeschema mcp --print-config              # 输出各客户端连接配置片段
```
接入 Trae / Cursor / VS Code / Claude 等客户端步骤见 [客户端接入指南（MCP）.md](./客户端接入指南（MCP）.md)。

## 6. HTTP 与可视化

```bash
./codeschema serve --http :8081
# /viz      —— 向量索引可视化（文档浏览/检索/状态）
# /openapi  —— OpenAPI 规范
# /docs     —— Swagger UI
# /metrics  —— Prometheus 指标
# /health   —— 健康检查
```
建议开启认证：配置 `server.auth_token` 后，请求带 `Authorization: Bearer <token>`。

## 7. 多租户（单实例多仓库）

配置 `tenants:` 列表（见 [配置参考](../1-生产层/配置参考.md) §tenants）。检索时 MCP 工具传 `project`，HTTP 传 `X-Tenant`/`?tenant=`；用 `list_projects` / `GET /projects` 枚举。未配置时行为与原单项目一致（默认租户）。

## 8. 常用环境变量

- `CODESCHEMA_SERVER_MCP_ADDR` / `HTTP_ADDR` / `AUTH_TOKEN`
- `CODESCHEMA_SCANNER_WORKERS`
- `CODESCHEMA_STORAGE_DSN` / `DRIVER`
- `CODESCHEMA_AI_API_KEY`

完整清单见 [配置参考](../1-生产层/配置参考.md)。
